# v2 兵士とジオラマ描画

## 構成

`v2_soldier_model.gd` は基本メッシュを組み合わせたオリジナルの兵士モデルです。ヘルメット、顔、胸部装備、ベルト、手、脚、ブーツを階層化し、ハンドガン、アサルトライフル、バーストライフルの輪郭と専用防具を描き分けます。軽装敵と重装敵は色、体格、胸部装甲を変えます。外部画像・音声・購入素材・生成サービスは使いません。

`v2_diorama.gd` は `SubViewportContainer` と独立 `SubViewport` 上に地面、低い土嚢、遠景、固定カメラ、柔らかな環境光と影を構成します。味方・敵モデルをIDで再利用し、戦闘イベントまたは記録再現イベントから短い射撃線、マズルフラッシュ、着弾を描画します。判定・ダメージ・乱数・保存は持ちません。

## 呼び出し

- `show_state(state)` は戦闘snapshotを受けて生存ユニットを配置します。
- `consume(events)` は戦闘演出イベントを一度だけ描画します。同じイベントを再度渡した場合は効果を増やしません。
- `set_active(false)` はSubViewport更新とポーズ更新を停止します。
- `set_preview(weapon, armor)` は同じ兵士素体を固定カメラのプレビューへ配置します。
- `show_replay(record, time, targets, pose)` と `consume_replay(events)` は記録された終点・命中・中心精度を描画し、命中判定やクリティカルを補いません。

モデルは最大3人の味方、12人の敵を表示します。一時効果は24個、イベント重複キーは512個まで保持します。SubViewportは親Controlの割当サイズへ追従し、430×240からアプリの最大表示サイズまで枠内に描画します。入力は `MOUSE_FILTER_IGNORE` です。

## 確認

`v2_art_tests.gd` は兵士の3武器モデル、防具表示、歩行ポーズ、独立viewport、親レイアウトへの追従、再現標的の再利用、イベント重複防止、効果上限、非表示時の停止を確認します。通常描画環境では画像を `work/outputs/v2-art-preview.png` に保存します。保存先は環境変数 `SLT_CAPTURE_OUTPUT` でも指定できます。headlessのdummy rendererでは画像取得を省きます。自動確認は人の試遊や面白さの評価を代替しません。
