# Aim Runner 0.24 表示部品

## 起動時のiris

`IrisIntro.start_boot(anchor, effects_enabled)` はクリック待ちへ入らずに開口を開始する。通常の演出時間は約0.8秒、演出を無効にした場合は短縮する。`finished` は表示アニメーション完了時に一度通知される。`advance(delta, active)`、`clear()`、既存の `start_wait()` / `open_from()` は表示制御用APIとして残す。アンカー位置は開始時に固定し、カメラ移動中に開口中心が跳ばない。アスペクト比を保ったピクセル距離で円形に描画し、ウィンドウのリサイズにも追従する。

## 3・2・1表示

`CountdownDisplay` はHUD内に置く表示専用部品で、`show_number(3)`、`show_number(2)`、`show_number(1)`、`clear()` を提供する。中央より少し上に大きく表示し、暗い輪郭を付けて明暗どちらの背景でも読めるようにする。入力を遮らず、時間計測・発音・射撃開始の制御は持たない。HUDの一部として追加するため、Pause画面より前面には出ない。

60秒測定など同じ表示を使う呼出側は、表示切替と秒単位の進行を所有する。カウント中に射撃を開始しない制御や、効果音の再生も呼出側で行う。

表示部品の単体ケースは既存の `progression_view_tests.gd` に追加している。統合後のGPU描画・実時計・配布EXEの確認は[検証報告](024-verification.md)を参照。実音声の聞こえ方は未確認。
