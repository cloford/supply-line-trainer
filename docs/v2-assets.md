# v2の素材と配布上の表記

兵士共通素体、ハンドガン／アサルト／バースト武器、専用防具、軽装／重装敵、地形・土嚢・遠景は、本プロジェクトのGDScriptで基本メッシュを組み合わせて生成したオリジナル形状です。無断抽出モデル、外部画像、有料購入素材、ゲーム内AI生成サービスは使用していません。

構え、発射、狙い直し、待機、歩行、被弾、退場は同じモデル階層への変形で表現します。発射・命中・着弾は判定済みイベントから表示し、アニメーションから追加ダメージを発生させません。射撃音・命中音は既存の自作合成音です。実銃録音とは表記しません。

Godot Engineとその同梱第三者コンポーネントの著作権・ライセンスは、Windows配布の`GODOT_LICENSE.txt`へ収録します。新しい第三者素材のクレジット追加はありません。プロジェクト生成素材の利用は外部素材ライセンスへ依存しません。公開リポジトリ全体のライセンス付与を、この説明だけで新たに行うものではありません。

検証画像と比較動画は隔離した確認用状態・合成測定から作成しました。実ユーザーのセーブや個人の射撃記録は含めず、配布PCK／ZIPへテストや個人データを入れません。
