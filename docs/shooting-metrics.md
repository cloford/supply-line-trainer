# 射撃の参考比較 v1

## 計測の定義

`q = 1 - clamp(射線と標的中心の最短距離 / 半径, 0, 1)`。外れは0です。既存の命中レイの結果を使い、計測用の追加物理レイは発射しません。従来の採点には変わらず `pow(q, 1.5)` を渡します。

| 武器 | 中心への近さ | 第2項目 |
| --- | --- | --- |
| ハンドガン・バースト | 全実発射のq合計÷実発射数×100 | 撃破数÷計測時間×60（体/分） |
| オート | 射撃中のq時間積分÷射撃時間×100 | 命中追従時間÷計測時間×100（有効追従） |

バーストは予定弾やクリック数を数えません。撃破追加点は計測に入りません。オートの発音数や描画フレーム数でも平均しません。既存の「追従率」は命中追従時間÷射撃時間で、今回の有効追従とは別です。発射・射撃時間0の中心指標は「—」。処理ペースは反応速度ではありません。

計測時間は既存の訓練経過時間を使い、移動・照準調整・非射撃時間を含みます。カウントダウン、一時停止、フォーカス喪失による停止は除きます。

## 比較条件

`ShootingMetrics` の定数へ、10秒、実発射10発（単発／バースト）、実射撃3秒（オート）、最大3件を集約しました。正常終了・完全な計測値・訓練中に関連設定変更なしの記録だけが対象です。科学的な上達判定の閾値ではありません。

武器・難易度・FOV・適用された度/count係数・metrics_version・training_rules_versionで照合します。FOVは小数4桁、実効感度は小数8桁へ正規化し、感度プリセット名やDPIだけでは区別しません。FOVと実効感度は開始時に固定記録し、途中で変更後に元へ戻しても対象外です。

開始順を保存して直近から選び、現在ID・重複ID・未来の記録・異版を除外します。各基準値は分子合計÷分母合計です。百分率の単純平均や最高記録選択ではありません。百分率差はポイント、処理ペース差は体/分です。表示桁に満たない差は「ほぼ同じ」とします。

自由移動・ランダム配置・練習の長さによる疲労やばらつきは除去しません。比較は参考で、能力や外部FPSでの上達を保証しません。

## 保存と境界

セッションごとに `metrics` へ生集計・設定・版・意識項目・適否理由を保存し、終了時の `shooting_comparison` へ対象ID・件数・合計値を保存します。履歴が200件で切られても別の基準に差し替えません。旧記録は推測補完せず「比較データなし」とします。

15秒・一時停止時の累積チェックポイントと同じ記録へ付加するだけです。ポイント付与経路は既存 `TrainingLedger` のみです。異常終了は保存済みまで復元し、比較基準には入れません。scoring_version=4、metrics_version=1、training_rules_version=1を分けています。初回バックアップは `user://save_before_metrics_v1_6.json`、既存バックアップを上書きしません。コピーに失敗したら保存を禁止します。

- A：`ShootingMetrics` のbullet/tracking/snapshotと、mainの既存命中レイへの接続。
- B：既存 `Balance.score_and_reward` と `TrainingLedger`。Aの新指標を報酬へ渡しません。
- C：`ShootingMetrics.comparison`。入力記録を変更しません。
- D：`ShootingMetrics.presentation` が表示モデルを作り、`ShootingReview` が描画します。UIに比較式を重複させません。
- E：既存 `GrowthGoal`・部隊戦闘。結果の購入目標は射撃比較と別部品です。

改善案2用の購入前後比較・ETA・演出追加、改善案3用の配点変更・稼ぎ方の抑制は実装していません。後者には同一セッションIDの獲得点・時間・実発射・命中・撃破・射撃・追従・生qを再利用できます。毎フレームの座標や全イベント保存、外部送信は追加していません。
