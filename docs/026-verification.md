# Aim Runner 0.2.6 検証

- 版番号比較、更新表示、自動適用の許可条件、保存・進行を含む既存の自動テスト10本を実行した。実行中の版と公開最新版の一致、確認時刻、編集中の自動適用の抑止を確認した。
- GPU描画で1280×720と1920×1080のメイン画面・更新設定を確認した。検証は自動実行で、人による試遊は実施していない。
- Windows配布ZIPの全ファイルを展開照合し、既存の更新検証に通ることを確認した。ZIPのSHA-256は `c18f795a99d3d6c03e5c0d20f011683c2e78090d40b1deef7c8b167272a36067`。
- 公開前に、隔離した0.2.5の配布EXEでテスト起動用のPCKから公開版のPCKを読み込み、98リソースをハッシュ照合した。候補ZIPを旧版の更新検証に渡し、ゲームの更新ボタン、PowerShell補助による旧ファイルの退避と差し替え、0.2.6配布EXEでの起動確認を通した。差し替えたEXE・PCKのハッシュと、テストセーブのクレジット・感度・案内既読の保持を確認した。
- 公開後は同じ隔離手順で、0.2.5がGitHubの正式リリースを検出し、公開ZIPをバックグラウンド取得して、再起動とセーブ保持まで完了した。0.2.6配布PCKからの正式API照会では、実行中と公開最新版がともに0.2.6と表示され、確認時刻が記録された。
- メイン画面での自動適用は許可条件を自動テストで確認した。次版の正式公開ZIPへの自動適用は、次回の公開時に検証する。
