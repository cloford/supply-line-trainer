# 0.24の確定範囲

2026-11-07のユーザー指示。確認ベース・着手時の最新正式版は0.23、次の未使用タグは0.24。Windowsで実装・検証・配布し、GitHub PUBLIC・版別Discussion・日本語資料を更新する。実ユーザーセーブを破壊しない。

## 起動フロー

通常起動は保存と個人設定を読んだ後、前回の選択によらずハンドガン・自由練習・無制限へ入る。準備画面を一瞬も描画しない。暗い訓練場に最初の静止標的を描き、出現音を一度鳴らし、自動アイリス（初期値約0.8秒）を開く。クリックや撃破を開始条件にしない。続いて大きい3・2・1を各約1秒表示し、消えてから射撃と計測を始める。旧「中央を撃って開始」の待機を置換する。

起動演出は毎通常起動で行い、一時停止再開・部隊復帰で繰り返さない。準備・部隊・記録は必要時にEscなどから利用可能にする。真の移行通知・破損・保存失敗は安全な説明・再試行から起動へ進め、準備画面経由や無視した上書きをしない。旧解放・クレジット・プロフィール・設定・記録を保持する。

開口・カウントダウン中は射撃不可、その時間と入力を練習時間・命中率・クレジットへ混ぜない。押しっぱなしを初弾へ持ち越さない。描画前の時計進行、二重減算、非表示HUDでの開始を防ぐ。大きな数字はHUD領域内、照準・標的に被らず、暗転やパネルの裏へ隠れない。以後の新規自由練習・60秒測定も必要な3秒表示を正しく出す。FOV・感度・視点・標的位置を開始時に飛ばさず、音量・演出抑制を尊重する。

## 停止・保存

0.23の`_open_pause`→`_save_current`→worker完了待ちと同期保存を候補として実測する。新規・合成大履歴・有効測定大履歴、保存待ちなし／保存中でEsc応答とフレーム停止、UI生成・一覧更新・snapshotの内訳を記録する。

Escでは先に計時・標的・射撃を停止し、保存完了やjoinを待たずメニューを表示する。整合したsnapshotで非同期要求し、保存中も描画・操作を維持する。未保存と保存済みを区別し、控えめな保存中／失敗表示・再試行を行う。Esc連打と再開の競合を防ぎ、pauseのたびに履歴やUIを作り直さない。

終了・更新・購入・採用・条件変更などの永続化が必要な操作は確定後だけ反映し、待機が必要なら処理中と表示して描画を止めない。保存保護を削らず、別スレッドはSceneTreeやライブDictionaryを扱わず、古い結果で残高・成果を巻き戻さず、同じ一時ファイルを複数writerで競合させない。

## 武器の公開段階

新規はHGだけ通常名・アイコン。未解放は黒いシルエット・???・条件と不足数だけを表示し選択不可。既存の撃破・AR有効追従という達成の定義と0／10／100／500／1,500条件を維持する。空撃ちは加算しない。5達成で右一覧を登場させ、解放済みと直近の未解放一つだけを表示する。達成後は名前・通常アイコンと練習選択を公開し、現在武器は自動変更しない。

準備・条件変更・一覧・説明などから未解放名や通常アイコンを漏らさない。既存解放を再ロックせず、起動HGの選択と解放状態を混同しない。

## 完成確認

新規の最初の描画から準備非露出→暗い標的・音→自動開口→3・2・1→HG無限→最初の実績→5一覧→10公開を確認。既存は保存状態保持・HG開始・旧実績再通知なし・解放武器への後の切替を確認する。開口／カウントダウン／射撃／保存中のEscと連打、フォーカス喪失復帰、部隊・設定往復、失敗再試行、終了再起動で時計・入力・成果・購入の二重処理や巻き戻りがないことを確認する。

720p・1080p・別比率で実GPU描画し、数字の描画順・照準中心・FOV・標的条件を確認。全選択経路と9→10、99→100などの境界を検査。既存現行テストへ必要例を追加し、旧版一式は複製しない。配布版の操作・自動テスト・人の試遊を区別し、原因として確認した事実と推測、未確認事項を報告する。

保存・停止・起動・入力・統合はSol 6.1、表示部品はLuna 6.0、独立レビューは別Sol 6.1。Astraを使用しない。
