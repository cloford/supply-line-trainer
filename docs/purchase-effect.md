# 購入前後の比較

`PurchaseEffect` は変更直前の部隊、敵残耐久H、戦線、購入内容と個数を取得し、変更後状態と比較する。実戦・プレビュー・購入後比較は `Balance.army_dps` を共用する。既存の引継ぎ倍率を含み、戦闘力・価格・敵の式は変更しない。

- T0=H/D0、T1=H/D1、短縮秒=T0−T1、時間短縮率=1−D0/D1。
- DPS上昇率ではない。丸め前に計算し、×5／×10も実際の購入後レベルから算出する。
- 購入ボタンに時間短縮率、詳細tooltipにDPSを表示。購入保存が成功したときだけ戦場上部へ2.6秒表示する。表示待ちや確認ダイアログは設けない。
- 次の成功購入で置換する。保存失敗は比較を消して失敗理由を表示し、ポイント・部隊・目標を戻す。重複入力は新しい通知を起動しない。
- 通知の秒数は購入時点のHを固定する。戦線が変わると秒数行を消し、短縮率と強化内容は残す。画面を離れると消え、再表示・再起動では再生しない。通知はセーブに追加しない。
- 残耐久0以下、非有限、DPS0以下・非有限なら時間比較なし。1秒未満はその旨を表示し、微小率は0.1%未満とする。現在減り続けるETAとは別の参考値。

表示処理は `PurchaseEffectView` が計算済みのtitle/headline/timing/detailを描画するだけ。計算のための戦闘進行・保存・ポイント消費・目標変更はない。

改善案2単独の確認：`purchase_effect_tests`、`scoring_regression_tests`（v1.6.1との同じ実レイ入力）、`growth_tests`、`battle_tests` が成功。3武器の採点・端数・q集計が完全一致し、DPSが変更前の計算と一致した。報酬検証の差分とは別コミットへ分離する。
