# 改善案2・3の変更前基準

基準：v1.6.1、コミット `68686ac`。着手時の作業ツリーはクリーン。改善案2と報酬検証は別コミットに分ける。

- 採点版4、計測版1、訓練ルール版1。
- 武器係数：ハンドガン0.105、オート0.05、バースト0.075。難度倍率：1 / 1.08 / 1.16。
- 有効命中の基本：単発45、バースト各15＋3命中で撃破20、オート命中追従100/秒。
- 中心加点：各命中の `pow(q,1.5)` を使い、基本と同額まで。速度＋連続の合計は基本の20%まで。
- 増員価格：70＋Lv×24＋floor(Lv/10)×45、装備価格：120＋Lv×85。
- 人数：6＋増員Lv×4。戦闘力：人数×(1＋装備Lv×0.16)×引継ぎ倍率。実戦DPS：戦闘力×0.18。
- 戦線耐久と武器開放条件は `balance.gd`／`main.gd` の基準コミットを正とし、今回変更しない。
- 初期状態DPS=1.08、初回増員後DPS=1.8、初回装備後DPS=1.2528。H=70なら初回増員で64.8148秒→38.8889秒、短縮40%。DPSの66.6667%増とは別。

実ユーザーセーブはローカルだけで別名バックアップし、原本を変更しない。個人の記録・集計結果は公開リポジトリへ送らない。利用可能な記録には、武器をまたぐ同一利用者・対応条件の比較と、丸め前の採点用集計が不足している。過去の平均qや整数内訳から未保存の生値は逆算しない。

過去チャットの一般的な偏り懸念は確認したが、具体的な武器・再現入力・人間の対応記録は提供されていない。後段で再現入力と合成条件を調べ、収益差だけで不具合と断定しない。
