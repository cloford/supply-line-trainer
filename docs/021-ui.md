# 0.21 UI コンポーネント

`ProgressionView` は実績通知、武器と練習の一覧、実績一覧を描画する局所UIです。CanvasLayer内の最後に追加する全画面Controlとして使います。ルートはマウス入力を無視し、武器選択ボタンと実績画面の操作だけを受け取ります。ゲーム側の判定、解除条件、保存、モード切替は持ちません。

## 接続API

```gdscript
var progression_view := ProgressionView.new()
ui_layer.add_child(progression_view)
progression_view.weapon_selected.connect(_on_weapon_selected)
progression_view.notification_finished.connect(_on_notification_finished)
progression_view.roster_intro_finished.connect(_on_roster_intro_finished)
progression_view.closed.connect(_on_progression_closed)
progression_view.refresh(model)
progression_view.set_context(training, interactive, roster_visible)
```

`model` は次の辞書です。thresholdと実績・武器の定義は進行モデル側が唯一の情報源です。

```gdscript
{
  "total": int,
  "rows": [{"id": int, "name": String, "title": String,
            "description": String, "threshold": int, "unlocked": bool}],
  "achievements": [{"id": String, "title": String, "description": String,
                    "unlocked_at": String, "unlocked": bool}],
  "effects_enabled": bool
}
```

`refresh()` はノードのready前にも呼べます。ロック中の武器はUIで `???` と黒いシルエットにし、条件・現在値・残り達成数を表示します。`weapon_selected(weapon:int)` の値は表示行の `id` です。呼び出し側が選択後の停止解除や練習切替を担当します。

通常練習の `set_context(true, false, true)` では一覧を閲覧専用にします。停止画面の `set_context(false, true, true)` では解放済み武器の「選ぶ」ボタンを有効にします。狭い表示幅では見出しと条件文を短縮します。実績一覧は `show_achievements()` で開き、閉じるボタンまたは親側のEscape処理から `close_overlay()` を呼びます。`is_overlay_open()` は親側のEscape優先判定に使います。

解除通知は `enqueue_notification(achievement)` でFIFOキューへ追加します。通知表示中に次の通知を重ねず、`notification_finished(id)` を消費完了時に返します。親側は停止中・設定画面・フォーカス外で `set_notifications_active(false)` を設定し、通知時計を凍結します。動き抑制設定がfalseなら位置移動とフェードを省き、3秒の表示時間は保ちます。

## 描画

`WeaponIcon` は5種類の武器をコード描画します。外部素材や既存作品の画像を取り込まず、ロック中は各シルエットを低彩度で表示します。画面幅が1024px未満では一覧幅を最大34%にし、1280×720と1024×768を想定した余白でレイアウトします。GameViewport、FOV、標的配置には触れません。

コンポーネントのローカルチェックは `godot --headless --path . --script res://progression_view_tests.gd` で実行します。
