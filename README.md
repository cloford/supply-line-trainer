# Aim Runner — 0.2.6

Windows向けのエイム練習ゲームです。訓練場で練習しながら種目を切り替え、射撃記録から三人の部隊を作れます。

## ダウンロードと起動

**0.2.5からはゲーム内で更新できます。** 練習を終了してメイン画面に戻り、設定の「更新／情報」で「更新を確認」を押します。取得が済んだら「再起動して更新」を選びます。

0.25以前から移る場合や初めて遊ぶ場合は、最新ZIP全体を別フォルダーへ展開し、`SupplyLineTrainer.exe` を起動してください。同じ場所のPCKが必要です。[0.2.6正式リリース](https://github.com/cloford/supply-line-trainer/releases/tag/v0.2.6)

0.2.6ではメイン画面と「更新／情報」に、実行中の版・公開最新版との比較結果・確認時刻が表示されます。「メイン画面に戻ったときに自動で更新・再起動」を有効にして設定を適用すると、次回以降は取得と検証を済ませた更新をメイン画面で自動適用します。練習や編集中の操作を終えるまで待機します。

通常起動では保存と個人設定を読み、準備画面を経由せず訓練場へ入ります。小さな円の中の静止標的を、指の案内に合わせて通常の射撃で撃つと開口し、大きな **3・2・1** の後に無限自由練習を開始します。誘導の一発は通常の射撃成績や60秒測定へ混ぜません。初回に限り達成と実績へ一度反映し、再起動で繰り返し取得できません。

通常起動は、毎回ハンドガンの無制限自由練習です。起動後はTabで解放済み武器へ切り替えられます。起動誘導を飛ばすにはEnterを押します。一時停止や部隊からの復帰では練習を再開します。

破損や読み込み・保存の失敗は理由を表示し、原本を無視して新規データで上書きしません。旧v1から初めてv2系へ移る場合は、従来の設定のみの移行について説明してから開始します。

## 操作と画面

- マウスで照準、左クリックで射撃。自由練習中はWASDで移動できます。
- Escで一時停止。設定・部隊などへ進めます。メイン画面では「練習開始」「ターゲット編集」「部隊」「記録」「設定」を文字で選べます。
- **Tabを押している間**、右側に五つの武器と練習操作が並びます。時計・標的・射撃を停止してカーソルを出し、離すと一覧が閉じます。通常練習の3命中で初回の案内が出ます。最初に一覧を開くと案内の既読を保存します。
- Tab内の武器を選ぶと、前の記録を一度確定して別の練習へ移ります。3秒の待ち直しはありません。ロック中の武器は選択できません。
- 「ターゲット編集」はメイン画面とTabで共通です。赤は高配点、青は低配点。右ほど中心報酬が増え、端の報酬が減ります。適用で保存し、練習途中の適用では記録を分けます。60秒測定とグレネードは固定配点です。
- 練習終了はTabの「練習終了」、Escメニュー、または右クリック0.8秒長押しです。

標的の離散した出現時には短い自作合成のポン音を鳴らします。追従標的の移動や一時停止解除では再生しません。全体音量・射撃音量・演出設定を使用し、強い演出を抑える設定では開口も短縮します。

## 武器と達成

新規はハンドガンから始まります。最初からTabで五行を見られます。未解放行は黒いシルエットと???、条件・残り数を表示し、解放時に正式名称・通常の絵・選択操作が有効になります。

| 練習 | 累計達成の条件 |
| --- | ---: |
| ハンドガン | 初期 |
| アサルトライフル | 10 |
| バーストライフル | 100 |
| マークスマンライフル | 500 |
| グレネードランチャー | 1,500 |

達成は非ARの標的撃破一体、ARは標的上の有効追従累計1秒です。端数を保持し、空撃ちは加算しません。測定分は有効な60秒の完了時だけ反映します。部隊・記録の再現・兵士の試射は達成へ含めません。

兵士作成は累計100達成で解放します。既存の採用プロフィールや測定履歴がある人は利用権を維持します。60秒測定は固定条件・固定配点で、途中の武器変更は中断となり、採用できる完了記録にはなりません。グレネードは自由練習専用です。既存三武器の測定・手動採用とHG／AR／BR各1枠の部隊を維持します。自動・オフライン・突破による通貨収入はありません。

## 保存と旧版からの更新

保存先は従来の`%APPDATA%/Godot/app_userdata/Supply Line Trainer/save_v2.json`。製品名変更後も、更新用のGitHub URLとEXE/PCK/ZIP名には旧識別名を使います。

射撃と一時停止では進行をメモリへ反映し、保存要求を集約して非同期に保存します。**一時停止メニューが開いたこと自体は、ディスク保存完了を意味しません。** 保存中・失敗の状態を区別し、失敗した場合は最新の成果から再試行します。終了・更新・購入・採用・条件変更などの確定が必要な操作は、処理中を表示して保存の確定を待ちます。

既存v2の育成・設定・履歴・プロフィール・解放をそのまま読み込みます。0.25までの公開版からは手動ZIP更新を使ってください。新体系の0.2.9の次は0.2.10です。

Esc内の「検証用操作」から全データを初期化できます。**感度・照準・音・Tab案内の既読を含めて初期値へ戻します。** 確認画面から実行すると、初期化前データを別の場所へ退避します。

短い連続加点は一つの表示へ集約します。合計獲得額は常時確認できます。表示アニメーションによって報酬を増減させません。過去のクレジットは再精算しません。
