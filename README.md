# SUPPLY LINE TRAINER

エイム訓練でポイントを稼ぎ、自動戦闘する部隊を強化するWindows向け3Dゲームです。

現在のバージョンはv1.9.0です。v1.7への感想を受け、v1.8のUIを維持しながら、成長の節目と練習からの短い往復経路を追加しました。[今回の変更・検証・画面例](docs/continuity-verification.md)、[v1.8の第一段階改善](docs/stage1-verification.md)を参照してください。

更新ごとにバージョン番号と更新履歴を更新し、GitHubへの反映とWindows版の公開リリースを行います。

## 起動と更新

[Releases](../../releases) のWindows版ZIPを展開して `SupplyLineTrainer.exe` を起動します。同じフォルダーの `SupplyLineTrainer.pck` が必要です。Windows 10/11 64bit向けです。

v1.3.0以前から更新する場合は、最新版を手動で別フォルダーへ展開してください。セーブはユーザーデータ領域から引き継ぎます。v1.4.0以降は起動時にGitHubの安定最新版を確認し、取得後「再起動して更新」で保存して適用します。訓練中の自動終了はありません。設定の「更新／情報」で自動取得の無効化と手動確認ができます。

通信や検証に失敗しても現在の版を遊べます。更新時は旧EXE/PCKを残し、起動に失敗した場合は復旧します。詳細と手動復旧手順は [自動更新](docs/updater.md) に記載しています。インストール先は自分が書き込めるフォルダーを選んでください。

## 訓練

単発エイム／トラッキング／複数標的エイムと難易度を選んで「訓練開始」。全練習を初回から使えます。選択は次の起動でも復元し、訓練は自動開始しません。開始カウントダウン後、自分で終了するまで練習できます。

- WASD：移動
- マウス：視点、左クリック：射撃
- 右クリックを0.8秒長押し：結果へ。リングが満ちる前に離すとキャンセル
- Esc：一時停止。「練習を再開」「練習条件を変更」「部隊へ」「設定」「訓練を終了」
- 訓練準備・部隊・記録・結果ではEscによる画面切り替えなし

ハンドガンは単発、オートライフルは長押しで追従、バーストライフルは1クリック3発。複数標的エイムでは3命中で標的を処理し、狙いを切り替えます。旧セーブの解放フラグは保持しますが使用制限には使いません。長押し終了中・一時停止・フォーカス喪失中は射撃を止め、復帰時に押しっぱなしで発砲しません。

非訓練画面の移動先は共通の「訓練」「部隊」「記録」です。設定・ヘルプは補助操作。初回の短い案内は閉じられ、ヘルプは後から開けます。既存ユーザーへ案内を強制しません。

訓練HUDは経過時間・今回の獲得ポイント・命中率（オートは射撃時間に対する追従率）を中心に表示します。戦況表示を外しても自動戦闘は継続します。育成目標の常時表示は標準オフで、目標達成通知と別々に設定の「照準」で切り替えられます。

結果は「練習の結果」と「育成の成果」に分けています。「詳細」で比較条件を確認でき、読むことは精算の条件ではありません。「同じ条件で続ける」「条件を変更」「部隊へ」の位置は購入可能状態でも変えません。

一時停止→「部隊へ」→「練習に戻る」で、結果や準備を経由せず同じ練習へ戻れます。部隊を見る間は訓練時間・標的・反応と追従計測を停止し、部隊の自動戦闘だけ進みます。購入後の部隊・残高を保ち、視点・標的・成績・連続成功を再開します。「この練習を終了して結果へ」は別操作です。

「練習条件を変更」は簡易選択です。変更を確定すると旧記録を一度保存し、新条件で新しい練習を開始します。キャンセル・同条件は元の練習へ戻ります。旧結果は記録から確認でき、設定による比較除外の条件も従来どおりです。

## 射撃の参考比較（v1.6.0）

結果では「中心への近さ」と「標的処理ペース」（オートは「有効追従」）を表示します。同じ武器・難易度・FOV・実効感度の直近最大3件が参考基準です。中心への近さは外れを含み、採点係数を使わない指標です。自由移動・ランダム配置・疲労によるばらつきまでは除去せず、上達を確定する検査ではありません。

比較には10秒以上、単発／バーストは実発射10発以上、オートは実射撃3秒以上の正常終了記録を使います。短い練習も通常どおりポイントを受け取り、今回値は表示します。設定変更・中断復元・計測のない旧記録は基準に混ぜません。

結果の「次に自分が意識すること」は任意です。指定なしでも再挑戦でき、選択によって配点・難易度・射撃条件は変わりません。意識項目は開始前だけ表示します。練習記録の行を選ぶと、その回の値・条件・当時の比較を確認できます。[定義と保存設計](docs/shooting-metrics.md)も参照してください。

## ポイントと成長

「今回の獲得」の1Pが、そのまま部隊購入に使う1Pです。所持合計とは区別して表示します。基本点、中心追加、速さと連続成功の追加を武器別に調整します。中心追加は基本と同額まで、その他の追加は基本の20%までです。

赤い中心マークは狙う目安で、外側でも有効命中なら基本点を得ます。射線と中心の距離を標的半径で正規化し、中心へ近づくほど追加が増えます。詳しい加点表示は設定の「照準」で切り替えます。内部端数は次回へ持ち越し、表示・保存・終了時の整数ポイントを一致させます。短く終了し直しても丸めで稼げません。

ポイントは射撃成果からだけ増えます。時間経過、オフライン、戦線突破の報酬はありません。部隊や装備は射撃条件・感度・採点を変更しません。

部隊画面では「増員」「部隊装備」の2種類を購入します。右側の候補を増員／装備で切り替え、現在と未来のシルエット・効果・条件・残り総費用・不足額を確認して、成長の節目を目標にできます。「次の1回を目標」も選べ、旧目標は更新で勝手に節目へ置き換えません。準備・結果は選択中の一枚だけ、HUDは既存設定を尊重した任意表示です。購入可能になっても練習を止めません。

購入前に現在と購入後の隊列・外見と「突破時間 約○%短縮」を確認できます。×1／×5／×10の実際の購入内容から計算します。購入成功後は、同じ敵残耐久で比較した所要時間を2.6秒表示します。現在のETAが自然に減った分は購入効果へ混ぜません。戦線が変わると秒数を消し、表示待ちは不要です。[購入比較の仕様](docs/purchase-effect.md)を参照してください。

増員の節目は10／18／30／50／102人。列数・横の広がり・射撃参加兵・背景密度が通常表示に残ります。前景48人・背景72人までの代表表示で、人数増加に応じて全体を自動縮小しません。装備はLv.2でヘルメット、Lv.5で重装備、Lv.8で背部装甲・バイザー・長銃身と射撃線が更新されます。戦力は通常の各レベル購入で上がり、外見の節目に特別能力はありません。

v1.7.0では報酬の54合成条件と2候補を比較しましたが、調整根拠が不足したため配点を維持しました。ポイント/分は通常画面の技能評価へ追加しません。[比較表と配点維持の理由](docs/reward-decision.md)を公開しています。

集団計算に従って敵が退場し、強化後は突破見込み時間が更新されます。演出は追加ダメージを与えません。自動戦闘は起動中の準備・訓練・部隊・記録・結果で進み、一時停止・設定・フォーカス喪失中は止まります。

## 設定と記録

設定は「操作」「照準」「音」「更新／情報」の4カテゴリです。感度はCS:GO／VALORANT／Apex Legendsの通常視点を基準に、DPIとcm/360を表示します。FOVは4:3基準です。ADS、反動、入力遅延の再現は対象外で、互換係数は公式保証を意味しません。

射撃音と命中音は各3種類と「なし」。個別音量、試聴、連続成功による控えめな音程変化に対応します。音源は自作合成です。

練習記録には累計練習時間、射撃活動時間、回数、直近200件の履歴を保存します。命中率または追従率も確認できます。旧採点の履歴・自己ベストは「旧バージョンの記録」で区別して保管します。

## セーブ

v1.5.0では育成をリセットせず、移行前に `save_before_growth_v1_5.json` を一度だけ保存します。廃止された指揮官装備は、既知の所有品と有効な装備状態を重複なく恒久的な部隊強化へ引き継ぎます。未装備の購入品も有効です。装備レベルと次の価格は変えず、ポイント返金は併用しません。ポイント・端数・戦線・敵の残耐久・設定・練習記録と採点バージョンも維持します。

目標は種類・到達段階・通知状態を保存します。新しい節目目標は達成後も保持し、次の候補を自分で選びます。まとめ買いで通過しても達成し、ロード時に済んだ演出を再生しません。費用は実購入の各回価格を足し、不足額と区別します。訓練中は台帳への未反映分だけを加えます。部隊へ入る前に差分を保存し、失敗時は購入へ進まず再試行・再開が可能。購入保存が失敗した場合も残高・強化・目標を維持します。

v1.9は既存の目標辞書へ任意の節目種別・達成通知フラグを追加するだけで、新たなリセット移行はありません。既存の移行前バックアップ・保存保護・差分台帳を維持します。部隊を開いたまま終了・異常終了した場合も保存済みチェックポイントまで復元し、3Dの完全復元は行いません。

Godotのユーザーデータ領域 `%APPDATA%/Godot/app_userdata/Supply Line Trainer/save_v1.json` へ保存します。v1.4.0では育成リセットを行いません。旧クレジットを同額のポイントへ移し、部隊・装備・戦線・武器開放・設定・累計を保持します。

初回移行前に `save_before_v1_4.json` を作成し、既存バックアップを上書きしません。バックアップ失敗や破損したセーブの読込時には元ファイルへの保存を停止します。

成果は15秒ごと、一時停止時、終了時に累積差分として保存し、終了や復元で二重加算しません。異常終了時は最後の保存地点まで復元します。直近最大15秒程度の未保存成果は失われる場合があります。カウントダウンだけで終了した練習は回数へ加算しません。

v1.7.0から新しい記録へ採点前集計4値を任意領域として付加します。旧記録を推測補完・再採点せず、ポイントや端数も保持します。初回読込前に `save_before_reward_v1_7.json` を一度だけ作成し、コピー失敗時は元セーブを保持して保存を停止します。個人の履歴を外部送信する機能はありません。
