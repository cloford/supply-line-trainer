# Supply Line Trainer — 0.21

標的を撃ち、達成を積み、次の武器で別の練習を試すWindows向けゲームです。三武器の60秒測定から、自分の発射リズムを持つ三人の部隊も作れます。

## ダウンロード・旧版からの更新

[0.21正式リリース](https://github.com/cloford/supply-line-trainer/releases/tag/v0.21)の`SupplyLineTrainer_Windows_v0.21.zip`を別フォルダーへ展開し、`SupplyLineTrainer.exe`を起動してください。同じ場所のPCKが必要です。Windows 10/11 64bit、Godot 4.7.2 Compatibility renderer。

**旧1.x／2.xから0.21へは手動更新が必要です。** 公開済みの旧アップデーターは新番号を認識できません。ゲームを終了して新ZIPを展開・起動してください。0.21以降は0.22、0.23…、0.29の次は0.30という整数の連番体系を使い、旧体系より優先します。

**今回、既存v2の育成・クレジット・プロフィール・個人設定をリセットしません。** 保存先は従来の`%APPDATA%/Godot/app_userdata/Supply Line Trainer/save_v2.json`。セーブの削除は不要です。旧v1から初めてv2系へ移る場合だけ、従来の設定のみ移行が適用されます。異常終了では未保存の成果を失う場合があります。

## 遊び方

ハンドガンで自由練習を開始すると、最初の標的撃破で約3秒のゲーム内実績バナーを表示します。設定確認は必須ではありません。累計5達成で、右側へ解放済み武器と次の未解放一つのシルエット・`???`・条件・残り回数を表示します。

解放後も現在の武器を続けます。Escで一時停止し、一覧で選んで「再開」すると、現在の記録を一度閉じ、新しい練習へ切り替えます。通常射撃中の一覧は閲覧専用です。

操作はマウス照準・左クリック射撃、自由練習のみWASD移動。Escで一時停止／再開、右クリック0.8秒長押しか一時停止メニューで終了できます。準備・結果・部隊ではEscで画面を切り替えません。

|武器|累計達成の条件|練習|
|---|---:|---|
|ハンドガン|初期|単発エイム|
|アサルトライフル|10|トラッキング|
|バーストライフル|100|一クリック3実弾の複数標的エイム|
|マークスマンライフル|500|固定3×3の9地点に標的一つずつ|
|グレネードランチャー|1,500|実弾道・衝突・範囲攻撃|

500／1,500は初期調整値を維持しています。人による長時間試遊で調整済みの値ではありません。

「達成」は通常標的一体の撃破を一回、ARは標的上の有効追従累計1秒を一回とし、端数も保存します。GL一発で三体を倒せば三達成ですが、発射・命中弾数は各一発です。空撃ち・未撃破の命中・再現・試射・自動戦闘は加算しません。自由練習は達成境界で保存し、測定分は有効な60秒完了時だけ確定します。

グリッドは9地点を一巡するシャッフルで連続同地点を避け、中心精度・命中率・平均切替時間を確認できます。GLはガイドと実弾が同じ弾道・衝突を使い、半径2.2m・100ダメージの爆風を適用します。一発最大9クレジットで、複数撃破を300%の命中率として扱いません。跳弾・自爆・地形破壊はありません。

新しい二武器は自由練習専用で、専用60秒測定・兵士プロフィール・出撃枠を追加しません。既存三武器の60秒測定は維持し、練習解放後に利用できます。

## 実績・既存データ・部隊

実績は最初の撃破、5達成、追加武器の解放。クレジット報酬・能力倍率・Steam連携はありません。解除と通知既読を別に保存し、複数通知は一つずつ表示します。準備・停止メニューから実績一覧を確認できます。

旧v2には進行項目だけを後方互換で追加。残っている確かな撃破・追従の事実を集計し、得点から推測しません。使用履歴・採用プロフィール・有効測定回数のある既存三武器は再ロックしません。移行解除は既読とし、大量のバナーを再生しません。[移行の詳細](docs/021-core.md)。

部隊は従来どおりHG・AR・BR各一枠、最大3人。一回の測定を手動採用し、採用元の射撃リズム・命中率・中心由来のクリティカル率を使います。直前へ戻す操作、防具、防護、名前も維持します。部隊の無料加入は累計獲得0／1,000／3,000クレジット、各武器3回測定で無料防具、有限5段階のHP防護。FPSの練習解放とは別の条件です。

通貨は射撃成果のみ。時間経過・オフライン・自動戦闘・突破・実績の追加収入はありません。自動戦闘は起動中に進み、一時停止・設定・フォーカス喪失では止まります。[部隊の設計](docs/v2-spec.md)。
