# SUPPLY LINE TRAINER

エイム訓練でポイントを稼ぎ、自動戦闘する部隊を強化するWindows向け3Dゲームです。

## 起動と更新

[Releases](../../releases) のWindows版ZIPを展開して `SupplyLineTrainer.exe` を起動します。同じフォルダーの `SupplyLineTrainer.pck` が必要です。Windows 10/11 64bit向けです。

v1.3.0以前からは、今回のv1.4.0だけ手動で別フォルダーへ展開してください。セーブはユーザーデータ領域から引き継ぎます。以後は起動時にGitHubの安定最新版を確認し、取得後「再起動して更新」で保存して適用します。訓練中の自動終了はありません。設定の「更新／情報」で自動取得の無効化と手動確認ができます。

通信や検証に失敗しても現在の版を遊べます。更新時は旧EXE/PCKを残し、起動に失敗した場合は復旧します。詳細と手動復旧手順は [自動更新](docs/updater.md) に記載しています。インストール先は自分が書き込めるフォルダーを選んでください。

## 訓練

武器と難易度を選んで「訓練開始」。開始カウントダウン後、自分で終了するまで練習できます。

- WASD：移動
- マウス：視点、左クリック：射撃
- 右クリックを0.8秒長押し：結果へ。リングが満ちる前に離すとキャンセル
- Esc：一時停止。「再開」「設定」「訓練を終了」
- 訓練準備・部隊・結果ではEscによる画面切り替えなし

ハンドガンは単発、オートライフルは長押しで追従、バーストライフルは1クリック3発。武器は戦線進行で開放されます。長押し終了中・一時停止・フォーカス喪失中は射撃を止め、復帰時に押しっぱなしで発砲しません。

## ポイントと成長

「今回の獲得」の1Pが、そのまま部隊購入に使う1Pです。所持合計とは区別して表示します。基本点、中心追加、速さと連続成功の追加を武器別に調整します。中心追加は基本と同額まで、その他の追加は基本の20%までです。

赤い中心マークは狙う目安で、外側でも有効命中なら基本点を得ます。射線と中心の距離を標的半径で正規化し、中心へ近づくほど追加が増えます。詳しい加点表示は設定の「照準」で切り替えます。内部端数は次回へ持ち越し、表示・保存・終了時の整数ポイントを一致させます。短く終了し直しても丸めで稼げません。

ポイントは射撃成果からだけ増えます。時間経過、オフライン、戦線突破の報酬はありません。部隊や装備は射撃条件・感度・採点を変更しません。

部隊画面では「増員」「部隊装備」の2種類を購入します。準備画面で次に買う1回分の目標を選び、射撃すると不足ポイントが減ります。購入可能になっても訓練は自由に続けられます。終了後、結果の「部隊へ」から対象の購入欄へ進めます。まとめ買いを選んでいても、この導線では1回分に戻します。

購入前に現在と購入後の隊列・外見を比較できます。増員すると援軍が左から合流し、規模に応じて背後の代表隊列も厚くなります。部隊装備はLv.2でヘルメットと武器、Lv.5で防具と重火器が更新されます。同じ外見段階内の強化でも短い装備更新動作を表示します。購入すると次の目標を選び、準備画面へ戻って練習を続けられます。

集団計算に従って敵が退場し、強化後は突破見込み時間が更新されます。演出は追加ダメージを与えません。自動戦闘は起動中の準備・訓練・部隊・記録・結果で進み、一時停止・設定・フォーカス喪失中は止まります。

## 設定と記録

設定は「操作」「照準」「音」「更新／情報」の4カテゴリです。感度はCS:GO／VALORANT／Apex Legendsの通常視点を基準に、DPIとcm/360を表示します。FOVは4:3基準です。ADS、反動、入力遅延の再現は対象外で、互換係数は公式保証を意味しません。

射撃音と命中音は各3種類と「なし」。個別音量、試聴、連続成功による控えめな音程変化に対応します。音源は自作合成です。

練習記録には累計練習時間、射撃活動時間、回数、直近200件の履歴を保存します。命中率または追従率も確認できます。旧採点の履歴・自己ベストは「旧バージョンの記録」で区別して保管します。

## セーブ

v1.5.0では育成をリセットせず、移行前に `save_before_growth_v1_5.json` を一度だけ保存します。廃止された指揮官装備は、既知の所有品と有効な装備状態を重複なく恒久的な部隊強化へ引き継ぎます。未装備の購入品も有効です。装備レベルと次の価格は変えず、ポイント返金は併用しません。ポイント・端数・戦線・敵の残耐久・設定・練習記録と採点バージョンも維持します。

目標は種類・到達段階・通知状態を保存します。購入するまでは、画面移動や再起動、ほかの購入で勝手に変わりません。不足額は文字列整数で算出し、訓練中は台帳への未反映分だけを加えます。購入時に保存できない場合は、残高・強化段階・目標の変更を取り消して部隊画面に理由を表示します。

Godotのユーザーデータ領域 `%APPDATA%/Godot/app_userdata/Supply Line Trainer/save_v1.json` へ保存します。v1.4.0では育成リセットを行いません。旧クレジットを同額のポイントへ移し、部隊・装備・戦線・武器開放・設定・累計を保持します。

初回移行前に `save_before_v1_4.json` を作成し、既存バックアップを上書きしません。バックアップ失敗や破損したセーブの読込時には元ファイルへの保存を停止します。

成果は15秒ごと、一時停止時、終了時に累積差分として保存し、終了や復元で二重加算しません。異常終了時は最後の保存地点まで復元します。直近最大15秒程度の未保存成果は失われる場合があります。カウントダウンだけで終了した練習は回数へ加算しません。

## 開発と検証

Godot Engine 4.7.2、GDScript、GL Compatibility rendererを使用します。`project.godot` をGodotで開いてください。主要調整値は `balance.gd` です。外部アセット／プラグインは使用していません。

[検証と未確認事項](VERIFY.md)・[更新履歴](CHANGELOG.md)・[配布手順](docs/release.md)を参照してください。テスト、スクリーンショット、ローカルセーブは配布対象に含めません。
