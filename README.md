# Aim Runner — 0.25

Windows向けのエイム練習ゲームです。訓練場で練習しながら種目を切り替え、射撃記録から三人の部隊を作れます。

## ダウンロードと起動

[0.25正式リリース](https://github.com/cloford/supply-line-trainer/releases/tag/v0.25)の`SupplyLineTrainer_Windows_v0.25.zip`を別フォルダーへ展開し、`SupplyLineTrainer.exe`を起動してください。同じ場所のPCKが必要です。Windows 10/11 64bit、Godot Compatibility rendererを使用します。

通常起動では保存と個人設定を読み、準備画面を経由せず訓練場へ入ります。小さな円の中の静止標的を、指の案内に合わせて通常の射撃で撃つと開口し、大きな **3・2・1** の後に無限自由練習を開始します。誘導の一発は通常の射撃成績や60秒測定へ混ぜません。初回に限り達成と実績へ一度反映し、再起動で繰り返し取得できません。

初回はハンドガン、以降は最後に使った解放済み武器を復元します。不正な選択はハンドガンへ戻します。一時停止や部隊からの復帰では起動演出を繰り返しません。新規訓練・60秒測定には3秒の開始表示があります。

破損や読み込み・保存の失敗は理由を表示し、原本を無視して新規データで上書きしません。旧v1から初めてv2系へ移る場合は、従来の設定のみの移行について説明してから開始します。

## 操作と画面

- マウスで照準、左クリックで射撃。自由練習中はWASDで移動できます。
- Escで一時停止。設定・部隊・記録・種目選択などの画面へ進めます。再開では同じ練習の時計と標的を保持します。
- **Tabを押している間**、武器・練習パネルを表示してカーソルで操作できます。その間は時計・標的・射撃を停止します。離すと練習へ戻ります。
- Tab内の武器を選ぶと、前の記録を一度確定して別の練習へ移ります。3秒の待ち直しはありません。ロック中の武器は選択できません。
- 標的と調整のアイコンから、自由練習の配点を編集できます。赤は高配点、青は低配点。右ほど中心報酬が増え、端の報酬が減ります。確定前後は別記録になります。60秒測定とグレネードには適用しません。
- 練習終了はTabパネルの停止アイコン、Escメニュー、または右クリック0.8秒長押しです。

標的の離散した出現時には短い自作合成のポン音を鳴らします。追従標的の移動や一時停止解除では再生しません。全体音量・射撃音量・演出設定を使用し、強い演出を抑える設定では開口も短縮します。

## 武器と達成

新規はハンドガンだけを使用できます。5達成で一覧が登場し、以降はTab中に「解放済み＋直近の未解放一つ」を表示します。未解放は黒いシルエットと???、条件・不足数を表示し、選択できません。解放時に名前と通常アイコンを公開しますが、現在の武器は勝手に変わりません。

| 練習 | 累計達成の条件 |
| --- | ---: |
| ハンドガン | 初期 |
| アサルトライフル | 10 |
| バーストライフル | 100 |
| マークスマンライフル | 500 |
| グレネードランチャー | 1,500 |

達成は非ARの標的撃破一体、ARは標的上の有効追従累計1秒です。端数を保持し、空撃ちは加算しません。測定分は有効な60秒の完了時だけ反映します。部隊・記録の再現・兵士の試射は達成へ含めません。

兵士作成は累計100達成で解放します。既存の採用プロフィールや測定履歴がある人は利用権を維持します。60秒測定は固定条件・固定配点で、途中の武器変更は中断となり、採用できる完了記録にはなりません。グレネードは自由練習専用です。既存三武器の測定・手動採用とHG／AR／BR各1枠の部隊を維持します。自動・オフライン・突破による通貨収入はありません。

## 保存と旧版からの更新

保存先は従来の`%APPDATA%/Godot/app_userdata/Supply Line Trainer/save_v2.json`。製品名変更後も、更新用のGitHub URLとEXE/PCK/ZIP名には旧識別名を使います。

射撃と一時停止では進行をメモリへ反映し、保存要求を集約して非同期に保存します。**一時停止メニューが開いたこと自体は、ディスク保存完了を意味しません。** 保存中・失敗の状態を区別し、失敗した場合は最新の成果から再試行します。終了・更新・購入・採用・条件変更などの確定が必要な操作は、処理中を表示して保存の確定を待ちます。

既存v2の育成・設定・履歴・プロフィール・解放は保持します。セーブの削除・初期化は不要です。0.21以前の公開アップデーターには新番号の認識・適用に制限があるため、手動ZIP更新を使ってください。0.22以降も手動更新できます。実際の自動差し替え全工程の検証範囲は報告書を参照してください。

Esc内の工具アイコンは検証用操作です。「全データを初期化」は**感度・照準・音も含め全保存状態を初期値へ戻します**。通常操作から分離した確認が必要です。初期化前データは通常読込対象外へ退避します。通常更新で初期化する必要はありません。

短い連続加点は一つの表示へ集約します。合計獲得額は常時確認できます。表示アニメーションによって報酬を増減させません。過去のクレジットは再精算しません。
