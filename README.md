# Aim Runner — 0.24

Windows向けのエイム練習ゲームです。通常起動するとハンドガンの無限自由練習へ入り、射撃記録から三人の部隊を作ることもできます。

## ダウンロードと起動

[0.24正式リリース](https://github.com/cloford/supply-line-trainer/releases/tag/v0.24)の`SupplyLineTrainer_Windows_v0.24.zip`を別フォルダーへ展開し、`SupplyLineTrainer.exe`を起動してください。同じ場所のPCKが必要です。Windows 10/11 64bit、Godot Compatibility rendererを使用します。

通常起動では保存と個人設定を読み、準備画面を経由せず、暗い訓練場の静止標的から自動で円形の開口を広げます。約0.8秒の開口後、大きな **3・2・1** を各約1秒表示し、消えてから射撃と練習計時を開始します。クリックや標的撃破は開始条件ではありません。開始前の時間・射撃入力は得点やクレジットへ含めません。

前回の選択にかかわらず、起動時はハンドガン・自由練習・無制限です。解放済み武器や記録・クレジット・プロフィールをリセットするものではありません。一時停止や部隊からの復帰では起動演出を繰り返しません。新しい自由練習や60秒測定にも3秒の開始表示があります。

破損や読み込み・保存の失敗は理由を表示し、原本を無視して新規データで上書きしません。旧v1から初めてv2系へ移る場合は、従来の設定のみの移行について説明してから開始します。

## 操作と画面

- マウスで照準、左クリックで射撃。自由練習中はWASDで移動できます。
- Escで一時停止。設定・部隊・記録・種目選択などの画面へ進めます。再開では同じ練習の時計と標的を保持します。
- 一覧が出た後、射撃中は閲覧専用。Escから解放済みの武器を選び、再開すると旧記録を一度閉じて別の練習へ切り替えます。
- 練習終了はEscメニュー、または右クリック0.8秒長押しです。

標的の離散した出現時には短い自作合成のポン音を鳴らします。追従標的の移動や一時停止解除では再生しません。全体音量・射撃音量・演出設定を使用し、強い演出を抑える設定では開口も短縮します。

## 武器と達成

新規はハンドガンだけを使用できます。5達成で右側へ「解放済み＋直近の未解放一つ」の一覧が現れます。未解放は黒いシルエットと???、条件・不足数を表示し、選択できません。条件達成後に名前と通常アイコンを公開しますが、射撃中の武器は勝手に変わりません。

| 練習 | 累計達成の条件 |
| --- | ---: |
| ハンドガン | 初期 |
| アサルトライフル | 10 |
| バーストライフル | 100 |
| マークスマンライフル | 500 |
| グレネードランチャー | 1,500 |

達成は非ARの標的撃破一体、ARは標的上の有効追従累計1秒です。端数を保持し、空撃ちは加算しません。測定分は有効な60秒の完了時だけ反映します。部隊・記録の再現・兵士の試射は達成へ含めません。

マークスマンは3×3の一標的練習、グレネードは弾道・衝突・爆風の自由練習専用です。既存三武器の60秒測定・手動採用とHG／AR／BR各1枠の部隊を維持します。部隊加入の条件とFPSの武器解放は別です。自動・オフライン・突破による通貨収入はありません。

## 保存と旧版からの更新

保存先は従来の`%APPDATA%/Godot/app_userdata/Supply Line Trainer/save_v2.json`。製品名変更後も、更新用のGitHub URLとEXE/PCK/ZIP名には旧識別名を使います。

射撃と一時停止では進行をメモリへ反映し、保存要求を集約して非同期に保存します。**一時停止メニューが開いたこと自体は、ディスク保存完了を意味しません。** 保存中・失敗の状態を区別し、失敗した場合は最新の成果から再試行します。終了・更新・購入・採用・条件変更などの確定が必要な操作は、処理中を表示して保存の確定を待ちます。

既存v2の育成・設定・履歴・プロフィール・解放は保持します。セーブの削除・初期化は不要です。0.21以前の公開アップデーターには新番号の認識・適用に制限があるため、手動ZIP更新を使ってください。0.22以降も手動更新できます。実際の自動差し替え全工程の検証範囲は報告書を参照してください。
