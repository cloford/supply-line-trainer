# Supply Line Trainer

エイム練習の一回の記録から、自分の発射リズムを持つ少人数の兵士を作るWindows向けゲームです。現在の版は **v2.0.0**。全3武器の測定と、各武器一枠・最大3人の3D部隊を実装しています。

## v2への更新前に

**育成を刷新し、引き継ぐのは個人設定だけです。** 感度・基準ゲーム・DPI・FOV・クロスヘア・音・有効な表示／更新設定をキーごとに検証して移します。旧クレジット・部隊・装備・戦線・累計・履歴・自己ベスト・中断記録は新育成へ持ち込みません。

旧`save_v1.json`は上書きせず、日時付きバックアップを作ります。新方式は別の`save_v2.json`へ保存。新セーブ作成後は起動ごとの再移行・初期化を行いません。バックアップ・読込・保存失敗では原本を保全し、理由と再試行を表示します。更新のためにセーブを削除しないでください。旧版へ戻す場合も旧データを利用できます。

## 遊び方

1. 設定で感度・FOVを確認し、好きな武器を選びます。全3武器の練習・測定は最初から利用可能です。
2. **自由練習**は無制限。射撃成果からクレジットを得ますが、兵士プロフィールへは変換しません。
3. **60秒測定**は3秒カウントダウン後、有効時間60秒・固定位置・共通条件で測ります。視点は自由です。一時停止中は時間と標的も止まります。
4. 完了して1発以上撃つと、結果の短い記録再現とRPM・基準命中率・命中時クリティカル率を確認できます。命中ゼロでも有効です。
5. 「この記録を採用」で手動採用します。不採用でもクレジットと有効測定回数は得られます。
6. 部隊を見て、防具・防護を育て、再び好きな練習へ戻ります。

操作はマウスで照準、左クリックで射撃。自由練習のみWASD移動。右クリック0.8秒長押し、またはEscメニューから終了できます。

Escは訓練中だけ一時停止を開きます。再開・条件変更・部隊・設定・終了を選べます。部隊へ往復するだけなら同じ訓練記録を続け、時間・標的・視点・成績を保持します。条件を確定変更した場合は旧記録を一度閉じ、新条件で開始。測定中の設定適用も現在の測定を途中終了して新しい測定へ切り替えます。取消・同条件選択は元の練習へ戻ります。

## 三つの固定出撃枠

編成は **ハンドガン1・アサルトライフル1・バーストライフル1、最大3人**。同じ兵種を複製したり、空き枠を別武器で埋めたりはしません。

- 部隊Lv.1：ハンドガン枠を無料利用。
- 累計獲得1,000クレジット：アサルト枠が無料加入。
- 累計獲得3,000クレジット：バースト枠が無料加入。

解放前の武器でも測定・プロフィール採用は可能です。未測定の解放済み枠には、明確に「基礎兵士」と表示するゲーム標準値を使えます。解放済み兵種は出撃ON/OFFが可能です。

各武器の有効60秒測定を3回完了すると、専用防具を恒久・無料解放（最大HP+20%）。別に有限5段階の防護強化をクレジット購入できます。HPだけを上げ、射撃頻度・命中率・クリティカル率は変えません。加入・防具に二重の支払いはありません。

## 一回の記録と兵士の関係

N=実発射数、H=命中数、Q=命中弾の中心評価の平均から、RPM=N、P=H/N、命中時クリティカル率C=0.30Qを求めます。全攻撃のクリティカル確率はP×C、ダメージ倍率1.5。命中率を下限補正せず、別測定の良い部分を寄せ集めません。アサルトの弾の命中率と、従来の時間追従率は別の値です。

武器ごとに採用中・直前を各1件、元の射撃データと一緒に保持します。新採用・防具・防護・出撃変更は次区間か再挑戦から反映。交戦中の能力は区間開始時のままです。名前変更や直前への復帰で報酬は増えません。

実戦は記録の[0,60)の発射時刻列を、先頭・末尾の無射撃時間も含めて繰り返します。命中はP、命中したときだけCで確率判定。敵不在・死亡・停止時は個人時計を凍結し、まとめ撃ちを蓄積しません。

「記録の再現」は実戦とは別で、保存された発射・命中・外れ・着弾・標的を等速再生します。最初の発射0.5秒前から8秒間で、他の部分は省略と示します。「兵士の試射」は確率判定で現在と候補を比較する任意機能。再現・試射から通貨・測定回数・進軍は得られません。

## 自動進軍とクレジット

オリジナルのデフォルメ3D兵士がジオラマを進み、軽装・重装の敵と交戦します。区間ごとにHP回復。全滅すると撤退して待機し、無料再挑戦で未突破区間の敵も全回復します。装備・記録・突破済み区間は失いません。第一遠征は12区間、その後は希望者が継続戦線を選べます。

クレジットは自由練習・測定の射撃成果だけから得ます。得点1が1クレジット。途中終了でも獲得分は保存します。時間経過・オフライン・敵撃破・戦線突破・完走・自己ベストの追加収入はありません。購入で所持は減りますが、累計獲得と部隊レベルは下がりません。

戦闘は起動中の訓練・準備・部隊・記録・結果で進み、一時停止・設定・フォーカス喪失では止まります。訓練から部隊へ入る間は訓練だけを停止。非表示の3D部隊は描画を止めても戦闘計算を変えません。終了中の進軍は計算しません。

## 起動・保存・更新

[公開リリース](../../releases)のWindows ZIPを別フォルダーへ展開し、`SupplyLineTrainer.exe`を起動します。同じフォルダーのPCKが必要です。Windows 10/11 64bit、Godot 4.7.2 Compatibility renderer。

保存先は`%APPDATA%/Godot/app_userdata/Supply Line Trainer/save_v2.json`。既存の一意な差分台帳を使い、15秒・一時停止・終了時にチェックポイントを保存します。異常終了では保存地点まで復元し、途中測定を完了へ格上げしません。直近の未保存成果は失われる場合があります。通常履歴は200件、採用中・直前の元記録は別寿命で保護します。

自動更新は正式版の版番号・配布ZIP・サイズ・SHA-256を検証し、保存後の「再起動して更新」で適用します。訓練を勝手に終了しません。旧EXE/PCKの退避・起動失敗時の復旧を維持します。[更新の詳細](docs/updater.md)。
