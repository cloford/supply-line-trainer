# SUPPLY LINE TRAINER

エイム訓練で補給を稼ぎ、自動戦闘中の部隊を強化する小規模3Dゲームです。

![射撃訓練](docs/images/crosshair.png)

## 起動

[Releases](../../releases) からWindows版ZIPをダウンロードして展開し、`SupplyLineTrainer.exe` を起動してください。同じフォルダーの `SupplyLineTrainer.pck` が必要です。Windows 10/11 64bit向けです。

## 操作

- WASD: 移動
- マウス: 視点
- 左クリック: 射撃
- Esc: 一時停止／設定

準備画面で武器と難易度を選び、「60秒訓練を開始」を押します。ハンドガンは単発、オートライフルは長押し連射、バーストライフルは1クリック3発です。訓練中のEsc画面から途中終了できます。

「部隊画面」では、左側で増員・装備強化・補給拠点を購入し、右側で部隊の進軍を確認できます。訓練中に部隊画面を開くと訓練だけが停止し、自動戦闘と補給収入は継続します。「訓練へ戻る」で同じ訓練へ復帰します。

| ![初期部隊](docs/images/army_initial.png) | ![成長後の部隊](docs/images/army_advanced.png) |

設定画面は感度、4:3基準FOV、クロスヘア、音量に対応しています。

## 開発環境

- Godot Engine 4.7.2 stable
- GDScript
- GL Compatibility renderer
- 外部アセット／プラグインなし

プロジェクト編集時は `project.godot` をGodot 4.7.2で開いてください。主要な調整値は `balance.gd` に集約しています。

## 検証

実施済みの検証内容と未確認事項は [VERIFY.md](VERIFY.md) に記載しています。テスト用スクリプトはゲーム本体の書き出し対象から除外されています。

## 保存

進行、自己ベスト、設定はGodotのユーザーデータ領域に `save_v1.json` として自動保存されます。破損時は安全な初期値で起動します。オフライン補給は最大8時間、金額は戦線ごとの上限までです。

## 既知の制約

- Godotの `InputEventMouseMotion.relative` を使用しています。解像度変更時にゲーム側で倍率は掛けませんが、値はOS／Godotが提供する相対移動量であり、物理マウスカウントとの完全一致は保証しません。
- UIは論理Viewportとアンカーを基準に追従します。Windows表示倍率100%以外での実機操作は未確認です。
- CS系の基準 `0.022度 × 感度` を入力イベント単位に適用しています。武器挙動や入力遅延の完全再現ではありません。
- 実機での長時間プレイによる30〜45分バランスは、計算シミュレーションで調整した目安です。
